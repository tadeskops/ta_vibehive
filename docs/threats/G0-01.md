# Threat model · Slice G0-01 (Foundation skeleton)

Per `AGENTS.md §4.1`: every module ships with a five-line threat model.

1. **Assets in scope.** `index.html`, `404.html`, `assets/css/base.css`, brand images. No user data, no forms, no cookies, no JS.
2. **Trust boundaries.** Anonymous public reader ↔ GitHub Pages CDN. Repository push ↔ GitHub Actions. Workstation push ↔ local git hooks + pre-push identity lock.
3. **Top risks.** (a) Malicious commit from a non-owner identity — mitigated by `.git/hooks/pre-commit` + `pre-push` identity lock. (b) Supply-chain injection via a compromised Action — mitigated by pinning Actions to major versions and enabling Dependabot in G0-02. (c) Serving of stale/misconfigured HTML that dilutes CSP — mitigated by CI check `G4 · CSP presence`.
4. **Assumptions.** GitHub Pages TLS is trusted. GitHub Actions runners are trusted (single-tenant per job). The maintainer workstation is not the attacker.
5. **Follow-ups.** (a) Add SRI + vendored Alpine.js in G0-02. (b) Add `_headers` file (Cloudflare Pages compat) when hosting migrates. (c) Enable branch protection + required-status-checks on `main` after the first CI green.
